# 新居民实用词审计：住房、学校、工作与城市选择

核对日期：2026-08-20。这个审计回答的是“一个准备在西班牙长期生活的人，办事时是否容易遇到这些词”，不是新的场景课程，也不是法律、移民、保险或购房建议。

## 审计范围

本轮围绕六类高概率任务检查现有 2,152 张目录：

1. 租房、看房、签约、押金和住址登记；
2. 购房、按揭、估价、公证和关联保险；
3. 选校、入学、学校类型和校园服务；
4. 找工作、招聘信息、合同类型和工作许可；
5. 居留预约、证件、续期和社会保障；
6. 城市与区域选择，包括通勤、学校、医疗和生活环境。

## 审计发现

现有目录已经覆盖一批重要基础词，包括：`alquiler`、`inquilino`、`propietario`、`fianza`、`empadronamiento`、`contrato`、`abogado`、`seguro`、`matrícula`、`currículum`、`entrevista`、`salario`、`barrio`、`distrito`、`municipio`、`hospital` 和 `farmacia`。

缺口主要不在一般生活名词，而在“文件上会写、办事时必须看懂”的任务词：按揭与估价、合同角色和条款、学校录取、劳动合同类型、居留证件与预约，以及比较居住区域的固定表达。wordfreq 的通用语料会低估这类低频但高后果的办事词，因此本轮不按频率排名硬筛，而要求它们同时满足：

- 出现在西班牙官方任务说明或公共服务页面的真实语境中；
- 对长期居住者有清晰、可解释的使用场景；
- 是一个 canonical target 或不超过 3 个词的固定表达；
- 不与运行目录重复，不用阴阳、复数或屈折形式凑数量；
- 例句只帮助理解，不把长句变成输入目标。

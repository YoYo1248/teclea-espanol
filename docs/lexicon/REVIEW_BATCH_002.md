## 选择边界

- 只从本地 wordfreq 前 6,000 候选快照中选择，并保存精确排名。
- 优先单数 lemma、非变位词和跨地区可理解的中性用语。
- 排除专名、粗俗词、外语噪声、明显屈折形式和规则性阴阳重复。
- 依据 PCIC A1–A2 / B1–B2 清单做保守等级和领域映射；它不是官方逐词认证。
- 中文释义和短例句为 HolaDone 编辑内容，仍不冒充具名语言专家复核。

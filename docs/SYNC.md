# 无账号跨设备同步

Teclea Español 不要求邮箱、手机号或密码。第一台设备生成20位同步码，另一台设备通过二维码或手动输入同步码加入同一同步空间。

## 安全模型

- 同步码只保存在用户设备的 `localStorage`，不会以明文上传。
- 浏览器使用同步码派生空间 ID、写入凭证和 AES-256-GCM 密钥。
- Vercel Function 只接收空间 ID、派生后的写入凭证和密文。
- Upstash Redis 保存密文，不保存可直接解密数据的同步码或 AES 密钥。
- 二维码把同步码放在 URL fragment 中，fragment 不会随 HTTP 请求发送给服务器。
- 拿到同步码的人可以加入并修改这份学习进度，因此同步码应按密码管理。

这不是账户恢复系统。两台设备都丢失且没有保存同步码时，无法找回或解密云端记录。

## 同步内容

- 上次练习模式和词库
- 每日完成数量与连续学习记录
- 已完成词库
- 错题累计错误次数、复习进度和掌握状态
- 重音判定和音效偏好

## 合并规则

- 已完成词库取并集。
- 每日完成数量取两端较大值，避免同一份历史被反复相加。
- 错题取并集；累计错误次数取较大值，掌握状态采用活动时间较新的记录。
- 上次模式和设置采用更新时间较新的快照。

应用会在启动时合并云端数据，并在本地学习记录变化后延迟同步。断网时本地练习不受影响，下次联网再合并。

## Vercel / Upstash 配置

在 Vercel Marketplace 为本项目连接 Upstash Redis，确保 Production 环境存在：

```text
UPSTASH_REDIS_REST_URL
UPSTASH_REDIS_REST_TOKEN
```

也兼容旧式 Vercel KV 变量名：

```text
KV_REST_API_URL
KV_REST_API_TOKEN
```

连接后重新部署。`api/sync.js` 会把每个同步空间保存为一个 Redis 字符串记录，并限制单份密文最大为120 KB。

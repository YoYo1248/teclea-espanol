返回练习

本机保存什么？

  • 本地练习数据：当前课程、随机顺序、中途位置、完成状态、每日练习数、错题、重音模式、音效与语速偏好保存在浏览器 localStorage。
  • 默认不上传：未创建或连接同步空间时，上述练习数据不会发送到 HolaDone 的同步数据库。
  • 删除本机数据：清除本网站的浏览器站点数据即可删除本机记录；删除后无法恢复。

同意匿名使用统计后会发生什么？

  • 使用目的：用于判断用户是否真正开始、完成或中途退出练习，并改进轮次长度和模式衔接。
  • 发送内容：只手动发送练习开始、首次输入、完成、退出、模式、等级、项目数、耗时、错误次数和独立答对率等汇总事件。
  • 明确不发送：不发送用户输入的文字、具体练习词条、同步码、同步空间内容或完整网页地址；不启用自动点击、会话录屏、热力图或自动异常采集。
  • 服务商与标识：事件发送到 PostHog Cloud EU。同意后，PostHog 会在本机 localStorage 保存一个随机浏览器标识，用于计算回访与留存；本站不会将它与姓名、邮箱或账号绑定。服务商仍可能处理提供服务和安全防护所需的 IP 与技术请求信息。
  • 拒绝或撤回：选择“不提供使用数据”后不会发送使用事件，且网站仍可正常使用。可随时在设置中开启或撤回；撤回只影响之后的采集。清除站点数据会同时清除本机选择和随机标识。

主动开启同步后会发生什么？

  • 同步内容：当前练习位置、每日记录、单元掌握进度、错题和训练偏好会在浏览器内加密后上传。
  • 端到端加密：浏览器从 20 位同步码派生 AES-256-GCM 密钥。Vercel Function 与 Upstash Redis 只处理派生凭证和密文，不接收明文同步码或可直接解密的密钥。
  • 同步码责任：拿到同步码的人可以加入、修改或删除这份进度；它应当像密码一样保管。本项目没有邮箱账号，也无法替用户找回丢失的同步码。
  • 保存期限与删除：每次写入会将云端密文的自动过期时间续至 400 天。用户可在设置中立即删除云端数据；仅“停止本机同步”不会删除云端副本。

语音和托管的边界

  • 西语朗读：应用调用浏览器的 Speech Synthesis 接口。具体声音可能由浏览器或操作系统本地提供，也可能依设备厂商设置使用网络服务；请以你的浏览器和系统隐私说明为准。
  • 托管与存储：页面和同步接口由 Vercel 托管，可选同步密文由 Upstash Redis 保存。这些服务商可能处理提供服务所需的 IP、设备、请求与安全日志。
  • 外部链接：来源和开源说明会链接到 GitHub、Instituto Cervantes、Kaikki 等第三方站点；离开本站后适用对方的隐私规则。
使用选择

不需要跨设备时可以一直只用本地保存。需要手机与电脑共享进度时，再由用户在设置中主动创建或连接同步空间。

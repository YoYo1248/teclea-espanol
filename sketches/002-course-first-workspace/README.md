## Variant: Course-first workspace

### Design stance
把桌面首页当成学习工作台，固定紧凑的今日侧栏，把大部分宽度留给课程选择。

### Key choices
- Layout: 330px 今日侧栏 + 双列可滚动课程区
- Typography: 课程区阅读优先，宣传标题降级为侧栏品牌语
- Interaction: 筛选状态、课程 hover、继续按钮状态

### Trade-offs
- Strong at: 核心操作突出、筛选不截断、33 组课程更容易浏览
- Weak at: 营销式大视觉被压缩

### Best for
- 回访学习者和以快速选课、开始练习为主的产品

# Teclea Español — 西语拼写练习

一个兼容手机与电脑的西语学习 MVP，基于 Qwerty Learner 的训练机制进行修改，并加入独立设计的响应式界面、西语词库与重音输入流程。

## 修改声明

本项目是面向手机与西语学习场景的修改版本，训练机制以 Qwerty Learner 为上游参考，并从 2026-08-14 起进行了新的界面、移动端输入、重音判定、统计、课程数据与交互实现。项目整体以 GPL-3.0 发布，不提供任何担保。

## 已实现

- 三种练习模式：跟打、中文回忆、听写
- 逐字母即时判定；任意字符错误后整词自动重置
- 严格重音 / 忽略 `á é í ó ú` 两种判定规则
- 严格模式等待系统输入法完成字符组合后再判定，不使用固定倒计时
- 单词训练自动排除 `¿ ? ¡ !` 等句子标点，例句仍保留规范西语标点
- 听写时按住 `Tab`，或在手机长按字符槽，可临时查看完整拼写
- 实时用时、WPM、按键正确率和错误次数
- 正确按键、错误和完成三类音效
- 西语重音字母和 `ñ` 快捷输入
- 关闭浏览器自动纠错与自动大写
- 错误后整词重输，正确后展示例句与语言提示
- 浏览器原生西班牙语发音（Speech Synthesis）
- 39 组 A1–A2 练习，共 780 张卡：72 张生活短句（含 24 张西班牙路考指令）、48 张精编对话、300 张高频词与短表达、360 张常用动词变位
- 可按“短句 / 对话 / 高频 / 变位”、学习等级和生活场景筛选
- 高频顺序参考 wordfreq；词形与变位以 Kaikki / English Wiktionary 结构化数据核对
- 本地保存课程完成状态
- 无账号跨设备同步：20位同步码、二维码配对、浏览器端 AES-GCM 加密
- 错题累计错误次数，高错词在复习轮次中重复出现；连续两轮零错误后标记掌握
- 手机安全区、窄屏、电脑宽屏和低高度布局适配

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

## 启用云同步

前端会继续优先保存在浏览器本地；云同步需要为 Vercel 项目连接一个 Upstash Redis 数据库，并配置下面两项环境变量：

```bash
UPSTASH_REDIS_REST_URL=...
UPSTASH_REDIS_REST_TOKEN=...
```

Vercel Marketplace 某些版本也会注入 `KV_REST_API_URL` 与 `KV_REST_API_TOKEN`，项目同样支持。连接数据库后重新部署即可。详细的数据结构、安全模型和合并规则见 [`docs/SYNC.md`](docs/SYNC.md)。

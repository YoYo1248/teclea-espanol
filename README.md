# Teclea Español — 西语拼写练习

一个兼容手机与电脑的西语学习 MVP，基于 Qwerty Learner 的训练机制进行修改，并加入独立设计的响应式界面、西语词库与重音输入流程。

## 修改声明

本项目是面向手机与西语学习场景的修改版本，训练机制以 Qwerty Learner 为上游参考，并从 2026-08-14 起进行了新的界面、移动端输入、重音判定、统计、课程数据与交互实现。项目整体以 GPL-3.0 发布，不提供任何担保。

## 已实现

- 三种练习模式：跟打、中文回忆、听写
- 跟打与听写模式进入每张卡时自动播放西语发音
- 逐字母即时判定；任意字符错误后整词自动重置
- 严格重音 / 忽略 `á é í ó ú` 两种判定规则
- 严格模式等待系统输入法完成字符组合后再判定，不使用固定倒计时
- 单词训练自动排除 `¿ ? ¡ !` 等句子标点，例句仍保留规范西语标点
- 听写时按住 `Tab`，或在手机长按字符槽，可临时查看完整拼写
- 实时用时、WPM、按键正确率和错误次数
- 正确按键、错误和完成三类音效
- 西语重音字母和 `ñ` 快捷输入
- 关闭浏览器自动纠错与自动大写
- 错误后整词重输，正确后展示中文含义
- 浏览器原生西班牙语发音（Speech Synthesis）
- 548 张 A1–B2 练习卡：410 张单词、88 张短语、50 张高频动词原形
- 练习目标只保留单词和不超过 3 个词的短语；较长句子不再作为逐字输入目标
- 可按“单词 / 短语 / 动词原形”、学习等级和生活场景筛选
- 高频顺序参考 wordfreq；拼写与词形以 Kaikki / English Wiktionary 结构化数据核对
- 不把同一动词的不同人称和时态当成独立生词；旧变位数据保留给未来“短语境 + 单个目标词”模块，但不进入当前课程或错题库
- A1–B2 主题与交际功能参考 Instituto Cervantes 对应等级的课程框架，具体选词、中文释义与标签仍是项目教学编辑，不是官方认证词表
- 每轮随机排列；退出或刷新后从当前卡继续，错题复习不会覆盖普通课程进度
- 错题答对一项清除一项；仍答错的项目继续保留
- 本地保存课程完成状态、进行中的顺序和统计
- 手机安全区、窄屏、电脑宽屏和低高度布局适配

## 本地运行

npm run dev
```

构建：

```
